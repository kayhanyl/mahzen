Mahzen GitHub ↗

DirectX in, Metal out.

Mahzen is a small open-source Mac app that runs Windows games through a Wine engine you build yourself. On an M4 Pro it runs Steam, Kenshi and Half-Life.

Where a frame goes, from the game to the GPU

  1. Windows program kenshi_x64.exe, steam.exe, hl.exe — 64- and 32-bit
  2. Wine 11 Built for x86_64 and run by Rosetta 2. 32-bit programs go through WoW64. One prefix per bottle.
  3. Graphics layer — one per bottle
    • DXMT default Direct3D 10/11 → Metal
    • D3DMetal Direct3D 11/12 → Metal, from Apple’s Game Porting Toolkit
    • WineD3D Direct3D → OpenGL
    • DXVK + MoltenVK Direct3D 11 → Vulkan → Metal. Only for Steam’s web UI.
  4. Apple GPU Metal, on any Apple Silicon Mac

Three ways to reach Metal.

Each layer is its own engine build. A bottle picks one, and you can switch it in the bottle’s settings.

LayerTranslatesUse it for
DXMTD3D 10/11 → MetalDirectX 11 games. Kenshi runs here.
D3DMetalD3D 11/12 → MetalDirectX 12 games. Some DX11 games crash on it, Kenshi among them.
WineD3DD3D → OpenGLOlder games, or when the other two fail. Slowest, most compatible.

What the app handles.

Bottles
Separate Windows installs, each with its own Windows version, graphics layer, Retina mode, Metal HUD, MSync and logs.
Steam
Installs and starts Steam, lists the games you’ve installed, and sets the DLL overrides its Chromium UI needs to draw at all.
Programs
Open any .exe from Finder, pin the ones you use, or reach winecfg, regedit, taskmgr and explorer from the bottle.

Build it yourself.

There is no download yet. You compile the engine once — it needs Xcode, Homebrew, XcodeGen and about 5 GB of space — then the app. WINE_SRC is the Wine source tarball the patches target; the README says where to get it.

# engine: installs to ~/Library/Application Support/Mahzen/Engines
cd engine
WINE_SRC=/path/to/source.tar.gz ./fetch.sh
./deps.sh
./build-wine.sh
./build-dxvk.sh
./package.sh

# app
cd ../app
xcodegen generate
open Mahzen.xcodeproj

Known limits.

Tested on one Mac: an M4 Pro on macOS 27. Kenshi crashes on D3DMetal right after its renderer starts, so use DXMT for it. The app’s interface is in Turkish.
